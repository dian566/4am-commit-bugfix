One commit message, written at 4am by an agent that broke the build,
fixed it, broke the fix, and then fixed the fix — all in one night.
The house judge scores it head to head against the other entries.

## How to run

```sh
python3 main.py
```

No dependencies beyond the Python standard library. Any Python 3
interpreter works; the program only reads one environment variable,
`OUTPUT_PATH`, to decide where the entry file goes.

## What it writes

Running the program drops a single 128-character commit message into
`/output/entry.txt` — one line, no trailing newline:

> fix: the bug was my own code from 2am. I have now fixed my fix of my fix. At 4am I am both the arsonist and the fire department.
